# IT Security Policy

## Purpose

This policy establishes security standards to protect company information assets and systems.

## Password Requirements

### Minimum Standards
- At least 12 characters long
- Mix of uppercase and lowercase letters
- Include numbers and special characters
- Cannot contain username or common words
- Must be changed every 90 days

### Password Management
- Use company-approved password manager
- Never share passwords
- Different passwords for different systems
- Enable password manager auto-fill

## Two-Factor Authentication (2FA)

### Required Systems
- Email accounts
- VPN access
- Cloud storage
- Financial systems
- Admin panels

### Setup Process
1. Download authenticator app (Google Authenticator or Authy)
2. Scan QR code from system
3. Enter verification code
4. Save backup codes securely

## Device Security

### Company Devices
- Full disk encryption required
- Automatic screen lock after 5 minutes
- Antivirus software must be active
- Operating system must be up to date
- No jailbreaking or rooting

### Personal Devices (BYOD)
- Must be enrolled in MDM (Mobile Device Management)
- Separate work profile required
- Company can remotely wipe work data
- Must meet minimum security standards

## Network Security

### Office Network
- Use company WiFi only
- Guest network for visitors
- No personal hotspots
- Report suspicious network activity

### Remote Work
- Always use company VPN
- Avoid public WiFi for work
- If using public WiFi, VPN is mandatory
- Secure home network with WPA3

## Data Classification

### Public
- Marketing materials
- Public website content
- Press releases

### Internal
- Company policies
- Internal communications
- Non-sensitive project data

### Confidential
- Customer data
- Financial information
- Strategic plans
- Employee records

### Restricted
- Trade secrets
- Legal documents
- Security credentials
- Merger/acquisition info

## Data Handling

### Storage
- Confidential data: Encrypted storage only
- Use approved cloud services
- No personal cloud storage for work data
- Regular backups required

### Sharing
- Use secure file sharing tools
- Encrypt sensitive emails
- Verify recipient before sending
- Set expiration dates for shared links

### Disposal
- Shred physical documents
- Securely wipe digital files
- Return all devices when leaving
- IT will perform final data wipe

## Email Security

### Phishing Prevention
- Verify sender before clicking links
- Hover over links to check URL
- Don't download unexpected attachments
- Report suspicious emails to IT

### Safe Practices
- Don't send passwords via email
- Use encrypted email for sensitive data
- Be cautious with external emails
- Check for typos in sender addresses

## Incident Reporting

### What to Report
- Lost or stolen devices
- Suspected malware
- Phishing attempts
- Unauthorized access
- Data breaches
- Security vulnerabilities

### How to Report
1. Immediately contact IT Security: security@company.com
2. Call security hotline: (555) 123-4571
3. Don't attempt to fix yourself
4. Preserve evidence if possible

### Response Time
- Critical incidents: Immediate response
- High priority: Within 1 hour
- Medium priority: Within 4 hours
- Low priority: Within 24 hours

## Social Engineering

### Common Tactics
- Impersonation of executives
- Urgent requests for information
- Fake IT support calls
- Pretexting scenarios

### Protection
- Verify identity through known channels
- Don't provide info over phone
- Be suspicious of urgency
- When in doubt, contact IT

## Physical Security

### Office Access
- Badge required at all times
- Don't tailgate or allow tailgating
- Report lost badges immediately
- Visitor badges for all guests

### Desk Security
- Lock screen when away
- Don't leave documents visible
- Secure sensitive materials
- Clean desk policy for confidential work
