# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2024-01-15

### Added
- Initial release of AI Tracking Engine
- RAG query system with confidence scoring
- Document upload (PDF and Markdown support)
- Automatic question clustering
- SOP gap detection and prioritization
- Kanban dashboard with drag-and-drop
- Analytics dashboard with charts
- Weekly automated clustering job
- PostgreSQL database integration
- Qdrant vector database integration
- Together AI integration for LLM and embeddings
- Docker Compose setup
- Comprehensive documentation
- Sample documentation files
- Setup scripts for Windows and Unix

### Features
- Query interface with real-time answers
- Confidence score calculation (0-100%)
- Source citations for answers
- Low confidence flagging (<70%)
- Semantic similarity clustering
- Priority scoring algorithm
- 4-column Kanban workflow
- Drag-and-drop SOP cards
- Weekly trend charts
- Statistics dashboard
- Automated insights

### Technical
- React 18 + TypeScript frontend
- Node.js + Express backend
- Tailwind CSS styling
- @dnd-kit for drag-and-drop
- Recharts for analytics
- Winston logging
- Zod validation
- Docker containerization
